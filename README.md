# -Car-Rental-System
A simple Car Rental System built using Core Java and OOP concepts. It allows users to view available cars, rent and return cars, manage customer details, and calculate rental costs through a menu-driven interface.
🚗 Car Rental System

I built this Car Rental System using Core Java to practice object-oriented programming and understand how a real-world rental application works. The project provides a simple, menu-driven interface where users can explore available cars, rent a car, return it, and view active rentals.

While developing this project, I focused on writing organized code using classes, objects, constructors, methods, and encapsulation.

Features

- View all available cars and their rental prices.
- Rent a car by entering the car ID and customer details.
- Calculate the total rental cost based on the number of days.
- Return rented cars and update their availability.
- View active rental information.
- Handle invalid menu choices and incorrect rental-day inputs.

How to Run

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Open the terminal in the folder containing the Java files.

4. Compile the source files:
   
   javac Main.java Car.java Customer.java Rental.java CarRentalSystem.java

5. Run the application:
   
   java Main
